# 🚀 ReactJS Starter Application

A complete and clean starter template for building applications with **ReactJS**.  
---

## 🧩 Prerequisites

Make sure you have the following installed:

- **NodeJS 25**
- **Git**

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/Cadfemm/React.git
cd React
```

---

## 🐍 2. Check Node Version
Node version should be 25 if not please upgrade.
```
node --version
```

---

## 📦 3. Install Dependencies

Install all required packages using the `package.json` file:

```bash
npm i or npm install
```

---

## 🔐 4. Configure Keys (`.env` file)

Create a `.env` file in the project root and add:

```ini
REACT_APP_API_MAIN=your frontend API
REACT_APP_API_DJANGO=your backend API
```

> ⚠️ **Important:** Never commit your `.env` file to GitHub.

---

## ▶️ 5. Run the Application

Start the development server using **npm**:

```bash
npm start
```
